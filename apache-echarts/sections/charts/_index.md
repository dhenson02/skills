# Chart Types

| File | Read when |
| --- | --- |
| [bar.md](bar.md) | Bar/column: grouped, stacked, styling, widths/gaps, background |
| [bar-advanced.md](bar-advanced.md) | Bar race (animated ranking), waterfall |
| [line.md](line.md) | Line: numeric x, styling, labels, gaps, stacked, area, smooth, step |
| [pie.md](pie.md) | Pie, doughnut, center label, rose/Nightingale |
| [scatter.md](scatter.md) | Scatter/bubble, symbol shape and size |
| [custom-series.md](custom-series.md) | `type: 'custom'`, `renderItem`, registerable custom series (v6) |
| [geo-map.md](geo-map.md) | Maps: GeoJSON choropleth, SVG base maps, regions, map events |
| [geo-svg-advanced.md](geo-svg-advanced.md) | SVG map layout, plotting on SVG coords, unsupported SVG features |

Other series types (`heatmap`, `candlestick`, `boxplot`, `radar`, `funnel`, `gauge`, `graph`, `tree`, `treemap`, `sunburst`, `sankey`, `themeRiver`, `parallel`, `lines`, `effectScatter`, `pictorialBar`) follow the same option model; consult the [option reference](https://echarts.apache.org/option.html) and [examples](https://echarts.apache.org/examples).
