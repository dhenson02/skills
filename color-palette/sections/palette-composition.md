# Palette Composition

Complex UIs commonly need up to 10 colors × 5–10 shades.

## Greys

Almost everything is grey: text, backgrounds, panels, form controls.

- 8–10 shades. Fewer forces compromise ("between #2 and #3"); far more wastes decision time.
- Range: very dark grey (darkest text) → subtle off-white (background). Not true black.
- Steady increments between.

## Primary (1–2 colors)

Primary actions, emphasized navigation. Defines the site's perceived color, even though most surface area is grey.

- 5–10 shades.
- Ultra-light shades → tinted backgrounds (alerts, selected rows).
- Dark shades → text on tinted backgrounds.

## Accents

Use sparingly, but still give each multiple shades.

| Purpose | Typical hue | Example use |
|---|---|---|
| Highlight / new feature | yellow, pink, teal | "New" badge, feature callout |
| Danger / destructive | red | Confirm-delete button |
| Warning | yellow | Warning message |
| Success / positive | green | Positive trend indicator |
| Categorization | many distinct hues | Chart lines, calendar events, tags |

Categorization needs drive the accent count highest.
